# Image Converter

![Screenshot Placeholder 1](https://i.imgur.com/lFiEPJA.png)

An extension to convert images to PNG, JPG, WebP, or AVIF with a few clicks.

- [Installation and Setup](#installation-and-setup)

## Features

- Bulk image conversion from local files or URLs.
- Support for multiple formats: PNG, JPG, WebP, and AVIF.
- Simple and elegant UI with live progress indicators.
- Light and dark theme toggles.

## Installation and Setup

1. Clone this repository:
   ```
   git clone https://github.com/sanchxt/image-converter-extension.git
   ```
2. Navigate to the project folder:
   ```
   cd image-converter-extension
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Run the development server:
   ```
   npm start
   ```
5. Build the production bundle:
   ```
   npm run build
   ```

## Usage

1. Open your browser extension settings and load the unpacked extension from the **`dist`** folder.
2. Click on the extension icon to open the interface.
3. **Select** the source _(file or URL)_, choose the output format, and then click **"Convert."**
4. **Download** the converted image(s).
